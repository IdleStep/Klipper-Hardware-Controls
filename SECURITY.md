# Security

These macros switch heaters, fans and steppers. A bug that can leave a heater on, or a
fan or sensor guard that does not work, is a safety problem and worth reporting even
when nothing went wrong on your printer.

Report it privately with the "Report a vulnerability" button on the Security tab of
this repository, not in a public issue. Give the version, the firmware (Klipper or
Kalico) and the command that triggers it.

Supported: the latest release and `main`.
